## 🔍 核心算法

### HQ 材料計算初期品質

參考 ffxiv-best-craft 項目的實現：

```typescript
// 基於材料等級的加權計算
const totalLvCount = Σ(材料數量 × 材料等級)
const hqLvCount = Σ(HQ數量 × 材料等級)
const ratio = hqLvCount / totalLvCount
const maxInitQuality = 配方品質 × (材料品質係數 / 100)
const initialQuality = floor(maxInitQuality × ratio)
```

**為什麼這樣計算？**
- 高等級材料對品質影響更大（加權）
- 符合遊戲內實際邏輯
- 與社群認可的工具保持一致
