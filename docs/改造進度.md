# 改造進度

## 背景：與遠端既有實作的整合

本次改造一度建在過期的本地基準（`06d847d`）上，而 `origin/main` 當時已多出 39 個 commit，
其中已包含成熟的市場掃描器、需求清單（`/lists`）、生產紀錄（`/production`）與求解器設定彈窗。

因此市場與清單相關的實作**全部改用遠端既有版本**（那一套已歷經多輪實際使用中的 bug 修正
與評分模型重構），只移植遠端確實缺少、且經驗證的部分。

---

## 實際移植的內容

### 1. 修復「取得清單」故障

`origin/main` 的 `hooks/use-xivapi.ts` 仍指向 **Cafemaker（cafemaker.wakingsands.com）**，
該服務已停止運作，固定回傳 HTTP 530 / Cloudflare error 1016。

失效路徑：`fetchItem` 只走這個來源且失敗即 `throw` → 材料樹是 `Promise.all` 遞歸建構的，
任一節點拋錯整棵樹就 reject → `app/crafting/page.tsx` 的 tree 停在 `null`
→ **「材料樹」與「所需材料」兩個區塊同時整塊消失**。

現改為本地 msgpack 資料庫，並讓查詢失敗降級回傳最小物件而非拋錯。

### 2. 資料層本地化（msgpack 管線）

`npm run build-data` 於建置時產生 `public/data/*.msgpack`，執行時按需載入：

| 產出 | 內容 | 大小 |
|---|---|---|
| `recipes.msgpack` | 13,892 配方、800 等級表、11,341 可製作物品 | 1.21 MB |
| `items.msgpack` | 50,774 物品（42,679 筆繁中名稱、可交易與可 HQ 旗標） | 3.46 MB |
| `sources.msgpack` + `npcs.msgpack` | 採集點、地名、NPC 座標 | 337 KB + 2.99 MB |
| `collections/*.msgpack` | 13 個收集分頁 + 索引 | 3.90 MB |

**成效（對照 `origin/main` 實測）**

| 指標 | origin/main | 現在 |
|---|---|---|
| 最大 JS chunk | 10.7 MB | 1.6 MB |
| JS chunks 合計 | 14 MB | **3.4 MB** |
| 收集頁首次載入 | 34.8 MB 單一 JSON | 索引 701 B + 分頁 63 KB |
| 材料樹建構 | 10–12 秒 | **< 1 秒，且零網路請求** |

`data/collections_data.json`（33 MB）已移出 `public/`，不再被部署，僅作為建置輸入。

**資料正確性**：配方由 XIVAPI v2 產生，但數值語意源自 yyyy.games，兩邊已逐欄位交叉驗證
（`ItemResult`、`RecipeLevelTable`、四個 factor、`RequiredCraftsmanship`、`CanHq`、
材料組成、等級表九個參數），並固化成常駐測試。v2 另提供 yyyy.games 缺少的 `Stars`。

> 相容性注意：`items.msgpack` 額外收錄 `CanBeHq`，因為 `components/solver-settings-dialog.tsx`
> 依賴 `Item.canBeHQ` 決定哪些材料可勾選 HQ。漏收會讓可 HQ 的材料無法被選取。

### 3. 測試（遠端原本 0 個）

`npm test` — 70 項，5 個檔案：

| 檔案 | 內容 |

| `tests/simulator/crafting-engine.test.ts` | 耐久/CP 消耗、HQ 機率查表、進度與品質公式（含各 buff 倍率與比爾格的祝福特例） |
| `tests/data/upstream-canary.test.ts` | 上游可用性 canary + XIVAPI v2 與 yyyy.games 的數值一致性 |

## 已知剩餘

| 項目 | 說明 |
|---|---|
| `tw-items.json` 仍在 bundle（1.6 MB） | `lib/i18n/tw-translation.ts` 的 `getItemNameTw` 在 `app/market/page.tsx:662` 是**同步**呼叫。改讀 msgpack 需要它變非同步或接受首次渲染拿不到名稱，屬於市場頁的行為變更，風險大於 1.6 MB 的收益，故保留。 |
